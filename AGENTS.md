# Project Context
This is a personal website (personal CEO website) — a long-term digital archive and personal branding asset.

## Tech Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- next-mdx-remote (content)
- Supabase (dynamic features)
- next-themes (dark/light mode)

## Design
- Fonts: Plus Jakarta Sans (heading) + DM Sans (body)
- Palette: Dark navy + off-white + amber accent
- Vibe: Techy & warm

## Conventions
- Use `src/` directory structure
- Components in `src/components/`
- MDX content in `src/content/`
- Utility functions in `src/lib/`
- Always use TypeScript strict types
